# Security policy

`rsolv-host` runs on customers' GitHub Actions runners and holds their run tokens, so we treat
every vulnerability in it as serious.

**Report privately**, through GitHub's "Report a vulnerability" button on this repository
(Security tab), or by email to security@rsolv.dev. Please don't open a public issue.

We acknowledge reports within 2 business days and agree a disclosure date with you. Only the
latest `host-v*` release is supported.
